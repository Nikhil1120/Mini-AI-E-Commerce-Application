================================================================================
API DOCUMENTATION — MINI AI E-COMMERCE
================================================================================

Base URL (local):       http://localhost:8000
Base URL (production):  https://mini-ai-e-commerce-application-x1eg.onrender.com

Interactive docs:  /docs (Swagger)  |  /redoc

All authenticated endpoints require header:
  Authorization: Bearer <token>


================================================================================
AUTH
================================================================================

POST /auth/google
-----------------
Google OAuth login. Creates user as CUSTOMER if new.

Request:
  {
    "credential": "google-id-token"
  }

Response:
  {
    "access_token": "jwt-token",
    "token_type": "bearer",
    "user": {
      "id": 1,
      "email": "...",
      "role": "CUSTOMER"
    }
  }


POST /auth/dev-login  (DEV_MODE only)
--------------------------------------
Development login without Google.

Request:
  { "email": "admin@ecommerce.local" }


GET /auth/me
------------
Returns current authenticated user. Auth required.


POST /auth/logout
-----------------
Logout (client discards token).


================================================================================
PRODUCTS
================================================================================

GET /products

List active products.

GET /products/{id}
------------------
Get product details.


================================================================================
ADMIN PRODUCTS  (Admin auth required)
================================================================================

POST /admin/products
--------------------
Create product.


PUT /admin/products/{id}

Update product.


DELETE /admin/products/{id}

PUT /admin/products/{id}/stock?stock_quantity=50

================================================================================
CART  (Auth required)
================================================================================

GET /cart
---------
Get current user's cart.


POST /cart/items
----------------
Add item to cart.

Request:
  { "product_id": 1, "quantity": 2 }


PUT /cart/items/{id}
--------------------
Update item quantity.

Request:
  { "quantity": 3 }


DELETE /cart/items/{id}
-----------------------
Remove item from cart.


DELETE /cart
------------
Clear entire cart.


================================================================================
ORDERS  (Auth required)
================================================================================

POST /orders
------------
Create order from cart. Backend calculates total.


GET /orders
-----------
List current user's orders.


GET /orders/{id}
----------------
Get order details (customers can only view their own orders).


PUT /orders/{id}/items/{item_id}
--------------------------------
Update quantity on a pending unpaid order.

Request:
  { "quantity": 3 }


DELETE /orders/{id}
-------------------
Remove a pending, failed, or cancelled order.
Paid orders cannot be removed.


================================================================================
ADMIN ORDERS  (Admin auth required)
================================================================================

GET /admin/orders
-----------------
List all orders.


GET /admin/orders/{id}
----------------------
Get any order by ID.


PUT /admin/orders/{id}/status
-----------------------------
Update order status.

Request:
  {
    "status": "SHIPPED",
    "payment_status": "PAID"
  }


================================================================================
PAYMENTS
================================================================================

POST /payments/create-checkout-session  (Auth required)
-------------------------------------------------------
Creates Stripe session for latest pending order.

Response:
  {
    "session_id": "cs_mock_1_abc123",
    "checkout_url": "http://localhost:5173/checkout/mock?session_id=...",
    "order_id": 1,
    "mock_mode": true
  }


GET /payments/verify-session/{session_id}  (Auth required)
------------------------------------------------------------
Verifies payment status for the user's order.
In real Stripe mode, can sync status from Stripe if webhook is delayed.

Response:
  {
    "session_id": "cs_mock_1_abc123",
    "order_id": 1,
    "payment_status": "PAID",
    "order_status": "CONFIRMED",
    "verified": true,
    "mock_mode": true
  }


POST /payments/mock-complete  (mock mode only, Auth required)
-------------------------------------------------------------
Simulates checkout.session.completed webhook.

Request:
  { "session_id": "cs_mock_1_abc123" }


POST /payments/mock-fail  (mock mode only, Auth required)
---------------------------------------------------------
Simulates failed payment.


POST /payments/mock-cancel  (mock mode only, Auth required)
-----------------------------------------------------------
Simulates cancelled/expired checkout.


POST /payments/webhook
----------------------
Stripe webhook endpoint. Handles:
  - checkout.session.completed
  - checkout.session.expired
  - payment_intent.payment_failed

Disabled in mock mode.
